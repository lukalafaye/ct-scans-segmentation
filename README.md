Description of scripts :

`baseline.py` : baseline script of the challenge.

`build_probabilistic_data.py` : build a probabilistic pytorch dataset file from the data built with `build_tensor_data.py`.

`build_tensor_data.py` : convert the original data to pytorch dataset files.

`build_transform_tensor_data.py` : same thing with transforms.

`mask_rcnn.py` : mask rcnn model.

`unet.py` : unet model.

`unet_raidium.py` : unet model for raidium data (for the comparison between unet and voc)

`unet_voc.py` : unet model for raidium data (for the comparison between unet and voc)

`utils.py` : many tools to visualize masks and define loss functions.
